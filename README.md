# مذكراتي الدراسية · My Study Notes

موقع أكاديمي بسيط لتنظيم المذكرات والامتحانات، يعمل بالكامل في المتصفح دون خادم أو قاعدة بيانات،
ويحفظ بياناتك محليًا على جهازك. الواجهة عربية (RTL) مع إمكانية التبديل الكامل إلى الإنجليزية (LTR).

## المزايا

- **حساب برقم سري**: إنشاء حساب باسم ورقم سري، وتسجيل دخول لاحق. كل مستخدم يرى مذكراته فقط.
- **مذكرات منظمة**: اسم المادة، الدرس، ملخص، تاريخ الامتحان، وحالة الفهم (جيد / متوسط / يحتاج مراجعة).
- **لوحة متابعة**: عدد المذكرات، الامتحانات القادمة، ونسبة المواد التي تحتاج مراجعة.
- **عرض الامتحانات**: قائمة مرتبة زمنيًا مع تمييز الامتحانات القريبة والمتأخرة.
- **بحث وتصفية**: حسب المادة وحالة الفهم، مع ترتيب حسب التاريخ أو الأحدث إضافة.
- **وضع ليلي/فاتح** وواجهة عربية وإنجليزية.
- **تصدير واستيراد**: نسخة احتياطية بصيغة JSON لكل مذكراتك.
- **إدارة الحساب**: تغيير الرقم السري، حذف الحساب، وتسجيل خروج.
- تصميم متجاوب يعمل على الجوال والتابلت والحاسب، مع دعم لوحة المفاتيح وقارئات الشاشة.

## التشغيل

الموقع ثابت بالكامل (HTML/CSS/JS) ولا يحتاج أي build:

1. افتح `index.html` مباشرة في المتصفح، أو
2. شغّل سيرفرًا محليًا بسيطًا لعرضه على `http://127.0.0.1:8787/`:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

أو انشر المجلد كما هو على GitHub Pages.

## كيف تُخزَّن البيانات؟

- المستخدمون والمذكرات في `localStorage`، والمذكرات تحت مفتاح خاص بكل مستخدم: `msn.v1.notes.<userId>`.
- الجلسة في `sessionStorage` وتنتهي بعد 12 ساعة أو عند إغلاق التبويب.
- الرقم السري لا يُخزَّن كنص صريح: يُشتق منه هاش عبر **PBKDF2-SHA256** (150,000 دورة) مع `salt` عشوائي،
  مع بديل SHA-256 عند عدم توفر Web Crypto.

## حدود الحماية

هذا موقع واجهة أمامية فقط، لذا:

- البيانات محفوظة في متصفح جهازك ولا تُزامَن بين الأجهزة، وتضيع إذا حذفت بيانات المتصفح.
- الحماية تمنع الاطلاع العابر على أرقام الآخرين، لكنها ليست حماية بمستوى خادم؛ أي شخص لديه وصول
  كامل إلى جهازك وبيانات المتصفح يمكنه قراءة محتوى `localStorage` تقنيًا.
- لا تستخدم رقمًا سريًا تستخدمه في حسابات مهمة (بريد، بنك…). استخدم رقمًا خاصًا بهذا الموقع.
